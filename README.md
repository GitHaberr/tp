Система контроля поручений для малых фирм
Предлагаем применить идею личного списка дел к корпоративным задачам.
Начальник создаёт задачу - подчинённый видит её в своём списке - когда сделал, нажимает «готово» - начальнику приходит уведомление на подтверждение - задача закрывается только после двойного подтверждения.
Клиент отправляет статусы, сервер хранит иерархию и историю изменений.

- main — стабильная, постоянная ветка.
  - feature/auth — вход и роли.
  - feature/tasks — создание и список задач.
  - feature/status — статусы и уведомления.
  - feature/db — сервер и история
